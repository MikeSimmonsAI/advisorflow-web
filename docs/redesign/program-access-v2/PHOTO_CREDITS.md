# Program Access V2 - photo credits

Every photo on the Program Access cards, featured banner and preview thumbnails is bundled with the app
(`frontend/src/pages/program/v2/img/`). Nothing is hotlinked. Files: `<key>-card.webp` (720x330, the short wide
card), `<key>-wide.webp` (900x440, left side of the featured banner) and, for Commercial Cleaning,
`cleaning-accent.webp` (520x440, right side of the banner). Cropped, lightly colour-boosted (saturation 1.22,
contrast 1.08) and re-encoded locally with Pillow, to match the vivid treatment of the approved mockup.

## Rules

- A card's photo is chosen from the program and the industry the server recorded (`commandCenterModel.js`,
  `photoKeyFor`), never from a client's name; a new client gets a suitable photo by itself.
- No official third-party logo is drawn or invented. Cards show a plain icon tile for the kind of workspace.
- To replace a photo: drop a new `<key>-card.webp` (and `-wide.webp`) in the folder and update this table.
