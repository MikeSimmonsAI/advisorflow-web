# OLP — Overlooked Properties | proposed brand assets

This is a NEW brand-identity exploration, not a registered trademark or an authorized production rebrand. The previous AI mockup mark was only a visual reference and no usable source existed. These assets are original vector constructions from editable SVG paths; no font files are redistributed.

## Files
- OLP_logo_primary_dark.svg / PNG — stacked, transparent background; optimized for navy/charcoal UI.
- OLP_logo_primary_light.svg / PNG — stacked, transparent background; optimized for white backgrounds.
- OLP_logo_horizontal_dark.svg / PNG — wide app-header variant for dark UI.
- OLP_logo_horizontal_light.svg / PNG — wide app-header variant for light UI.
- OLP_icon.svg / PNG — logo mark for favicon/program tile; use textless icon at tiny sizes if legibility requires.

## Identity
- Main name: OLP
- Expanded name: Overlooked Properties
- Endorsement: Powered by BookaBoost
- Tagline in UI (not part of logo lockup): Find What Others Miss.
- Internal product identifier proposed: olp (only after reviewing existing entitlement/product registry; never create an alternate tenant/auth system).

## Usage and approval
Use these as prototype assets only on the OLP-specific BookaBoost branch. Match colors to the existing charcoal/navy/gold visual design. Do not replace the BookaBoost official logo in all other contexts. Do not claim these are final, legally cleared or trademarked. Reuse approved local image assets, not generated mockup photos, in production.

SVG text is converted to vector outlines for predictable rendering; the underlying fonts themselves are not included. The vector files can be edited in Inkscape, Illustrator, Figma, or other SVG-compatible software.
