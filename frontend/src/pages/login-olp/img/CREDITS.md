# OLP sign-in imagery

`bg-estate.webp` comes from `frontend/src/pages/wholesale/ds/photos/estate.jpg`. That photograph is already
licensed in this repository under the Unsplash License (free for commercial use; see that folder's
CREDITS.md). Unsplash id: photo-1568605114967-8130f3a36994.

The only changes were done locally: a colour grade (navy / charcoal / warm-gold tritone, keeping 35% of the
original colour so the lit windows stay warm) and a WebP re-encode. No AI-generated imagery is used.
